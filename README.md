# User Story M1S1
>
## Objective of the User Story
Record products along with their name, price, and quantity in a simple program. Calculate basic operations such as total units and approximate cost. Apply programming fundamentals: data input, variables, mathematical operations, and console output.

## Strategy
A logical structure was implemented, consisting of no more than 4 functions and 2 modules, to make the code easy to read; comments were also added to help users understand the code's syntax.
